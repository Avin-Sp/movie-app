# 🎬 MovieHub

A modern and responsive movie discovery web application built with React.

MovieHub allows users to explore movies, search through the collection, filter movies by genre, view movie details, and save their favorite movies.

## 🌐 Live Demo
https://Avin-Sp.github.io/movie-app/

## ✨ Features

- 🎬 Browse movies
- 🔎 Search movies with debounce
- 🎭 Filter movies by genre
- 📄 Movie details page
- ❤️ Add and remove favorites
- 💾 Persist favorites with LocalStorage
- 📱 Fully responsive design
- 🎨 Modern dark cinematic UI
- ✨ Smooth animations and interactions
- ⚡ Loading and empty states
- ❌ 404 and movie-not-found pages

Getting Started
1. Clone the repository
git clone https://github.com/Avin-Sp/movie-app.git
2. Navigate to the project directory
cd movie-app
3. Install dependencies
npm install
4. Start the development server
npm run dev
The application will be available at the local development URL provided by Vite.

📦 Build for Production
npm run build

To preview the production build locally:

npm run preview

The application will be available at the local development URL provided by Vite.
